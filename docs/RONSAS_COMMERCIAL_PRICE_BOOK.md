# RONSAS Commercial Price Book

**Status:** Governed commercial price book  
**Effective date:** 3 October 2026  
**Currency:** South African rand (ZAR)  
**Price basis:** Standard list prices are exclusive of VAT unless a written quotation states otherwise.  
**Commercial activation:** Current product promotions remain at R0 where explicitly marked. Standard list prices become chargeable only when the relevant product's entitlement and billing implementation is activated.

## Pricing architecture

RONSAS uses a consistent commercial pattern:

- **Free** — acquisition and product discovery.
- **Creator / Standard** — individual recurring use.
- **Studio / Pro** — higher-volume individual or small-team use.
- **Team / Agency / Enterprise** — collaboration, governance or higher-volume use.
- **Usage / credits** — applied where variable AI/media infrastructure cost makes unlimited access economically unsafe.

This keeps list pricing understandable while preventing fixed subscriptions from silently absorbing unbounded provider costs.

## Product-specific pricing rationale

### Career Compass

Public South African career tools currently span low one-off prices through several hundred rand per month. My Job Concierge lists R100 per individual tool, R370/month Standard and R640/month Plus; RoleAlign lists one-off application packs from R29 to R299; GrowVert lists career-development packages from R850, with CareerClarity from R2,000. DataNest's proposed R149/R299 monthly structure deliberately stays below the higher-touch managed-service examples while leaving room for a free acquisition tier.

### Creative Studio

South African creator/marketing software and services establish a useful reference band: Suubi lists R799/month for Founder and R1,499/month for Studio, while GOAT Creative Solutions lists R3,150/month for a starter content-creation service and R10,800/month for premium managed content. Creative Studio is software rather than a managed production service, so R249/R699/R1,499 positions it below managed creative services while supporting higher-volume usage.

### ePublisher

ePublisher has hosted authentication, premium-over-quota handling, publishing/export workflows and billing surfaces in its implementation. The proposed R149/R399/R899 structure separates individual publishing from higher-volume or professional use without claiming a current paid entitlement.

### LyricSync Studio

The current implementation provides deterministic local lyric timing and LRC export with no external service dependency. Its proposed R99/R199 structure keeps the software inexpensive relative to cloud generation products while leaving room for premium workflow features later.

### Scene Song Spark

The current implementation is a deterministic scene/song ideation workflow driven by concept, mood, duration and scene count. R79/R199 is intentionally positioned as a lightweight creator utility rather than a compute-heavy subscription.

### Sovereign Forge

The current implementation is a governed development/build-tooling surface that generates project manifests with DataNest as source authority. A free Community tier supports ecosystem adoption; Pro/Team pricing is intended for professional workflow features, collaboration and support. Enterprise remains custom because governance, deployment and integration scope can vary materially.

### SyncVision

Current implementation evidence shows a compute-sensitive workflow covering storyboard/timing, visual generation, vocal sync, rendering, storage and provider usage measurement. International AI-video products are strongly credit-based: Kaiber lists $10/month Starter, $29/month Creator and $99/month Pro, while Pika lists $10/month Starter, $35/month Creator and $95/month Fancy, with credits and one-time top-ups. The current implementation provides channel audits, content ideas, trends, connections, monetisation and scheduling. vidIQ's current public plans use a free tier and credit-based paid tiers; its Max plan is listed at $39/month and Enterprise starts at $799/month. ## Financial-claim controls

1. R0 promotional access is a current-state pricing claim only where the product's active promotion is explicitly enabled.
2. Standard list price is a commercial price-book claim; it does not imply paid checkout is already active.
3. Annualized list value is arithmetic, not realised revenue.
4. Revenue, profit, customer counts, conversion, demand and forecasts require actual evidence for the relevant period.
5. Usage-heavy products must preserve measurable provider/infrastructure cost evidence before promising unlimited paid usage.
6. Discounts, VAT, refunds, credits, write-offs and excluded third-party costs must be separately disclosed where material.
7. No product may claim commercial availability beyond its actual entitlement/billing implementation state.
