# Boundaries Tree

The **Boundaries** tree defines DataNest tolerance boundaries and acceptance criteria for every execution surface.

It converts DataNest human–AI principles into machine-readable invariants. The assessor is fail-closed for missing core policy and produces evidence for review; it does not replace human judgment.

FREETREE is intentionally outside DataNest governance and synchronization. That isolation does not remove platform security, credential hygiene, applicable law, or the requirement that FREETREE cannot authorize canonical DataNest production.
